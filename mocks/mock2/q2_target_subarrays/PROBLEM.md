# Target Subarrays  (Medium, 35 points)

Count the contiguous subarrays of `a` whose elements sum to exactly `k`.
Values may be negative.

**Input:** the first line holds `n k`; the second line holds `n` integers.

**Output:** the count (it can be larger than 2^31).

**Constraints:** 1 <= n <= 200,000; -10,000 <= a[i] <= 10,000; -10^9 <= k <= 10^9

### Sample input
```
5 3
1 2 1 -1 3
```

### Sample output
```
5
```

Write your solution in `Solution.java` in this folder (class name must stay `Solution`).
